!2 End-to-end smoke test (TCP mode)

This page drives the built CLI (`dist/esm/cli.js`) as a real FitNesse SLiM server over TCP.
`$PWD` is replaced with the absolute repository path by `scripts/render-fitnesse.mjs` before the
run, so `COMMAND_PATTERN` and the import path always point at the checkout.

|import|
|$PWD/fitnesse/fixtures|

!3 Script table

A script-table *action* row normally alternates method and argument cells, so a call with more
than one argument ends the method name with `;` to switch that row to positional arguments.

|script|Calculator|
|add;|2|3|
|check|total|5|
|add|10|
|check|total|15|
|reset|
|check|total|0|

!3 Symbol round-trip

|reset|
|$sum=|add;|7|8|
|check|total|$sum|

!3 Typed fixture: method alias and list element types

`sum of` is a declared alias for `sumOf`, and `params: [listOf(Number)]` turns `1,2,3` into
`[1, 2, 3]`, so the total is the number 6 and not the concatenation `"0123"`.

|script|!-TypedCalculator-!|
|sum of|1,2,3|
|check|total|6|

!3 Query table

`query()` is invoked as an ordinary `call`; each returned row is a list of `field, value` pairs, and
FitNesse matches the rows in any order.

|query:Employees|
|name|age|
|Grace|45|
|Ada|36|

!3 Fixture output

`shout` writes to `console.log`. In TCP mode the protocol runs over the socket, so fixture output
goes to the process stdout, which FitNesse records as this page's stdout — no tunnel is involved.
Pipe mode is the transport that needs the `SOUT.:` tunnel; see the `PipeMode` page.

|script|Calculator|
|shout|
|check|total|0|
